Request 
curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"news_text": "Your news text here"}'

{
  "news_text": "Your news text here"

Response
{
  "success": true,

About TruthLens AI

TruthLens AI reads the text you give it and returns a label with the model's confidence.

It does not check sources, verify individual facts, or search the web. Treat the result as one signal to weigh alongside your own judgment and trusted reporting.

  • Machine LearningClassifies text as Fake or Real
  • NLPTurns raw text into model input
  • TF-IDFWeights words by how distinctive they are
  • Scikit-learnModel and vectorizer
  • PythonPrediction pipeline
  • FlaskWeb app and JSON API

TruthLens AI. Predictions are probabilistic and not proof of authenticity.
